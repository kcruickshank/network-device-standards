Storage & deployment

Settings

This browser (local)

Data is saved in this browser only. Good for testing and personal use. Use Export to back up or move data.

SharePoint lists (shared)

Data is stored in SharePoint lists on the site that hosts this page. Everyone with access to the site shares one catalog.

API server (shared)

Data is stored in a small shared server (FastAPI + SQLite) on your network. Everyone who can reach the server shares one catalog. A good option when SharePoint isn't available.

Enter the address of the Network Device Standards API server your team runs (ask whoever set it up). It must be reachable from your machine. Everyone who connects to the same server shares one catalogue, with the same conflict protection as SharePoint mode.
The page must be hosted on this same SharePoint site (upload it to a document library there). Eight lists are used, all created automatically if missing: NDS_Devices — the standard device catalogue
NDS_Accessories — accessories and the devices they fit
NDS_Links — datasheets and reference links
NDS_GoldenImages — approved software image versions
NDS_BOMs — bills of materials
NDS_Sites — sites and addresses
NDS_ChangeLog — audit trail of changes
NDS_Config — taxonomy, branding and settings
Sets the currency shown for all device and accessory unit costs. Switching currency converts every stored price using the exchange rate below, so the figures stay meaningful. The currently active currency is EUR (€).
When an admin is set, editing the titles, subtitles, logo and section headings, and deleting change log entries, all require the admin sign-in. The password is never stored — only a salted PBKDF2-SHA256 hash. Note this is an in-page guardrail: in SharePoint mode, list permissions remain the authoritative control.
